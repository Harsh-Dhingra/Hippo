# Code of conduct

## The short version

Be someone people want to work with. Assume good faith, say what you mean, and
take disagreement about the work as being about the work.

## The longer version

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. It is a good document and there is no reason to write a worse one.

**Reports go to the maintainers**, in confidence, at the address in
[SECURITY.md](SECURITY.md). If a report concerns a maintainer, it goes to the
others, and that maintainer takes no part in handling it.

## What we will act on

Harassment, sustained disruption, and personal attacks. Also: repeatedly
relitigating a decision after it has been made and explained, which is a way of
exhausting people rather than persuading them.

## What we will not act on

Direct technical criticism. "This adds a second read path to content and that is
not acceptable" is not rudeness, it is review. This project's bar is strict in
specific places for stated reasons, and holding it is the job.

The distinction we care about is whether a comment is about the work or about
the person. Almost everything else follows from that.
